Track 1 · AI for the analyst

SOC Brief

Plain-English triage for IDS alerts, phishing mail, and AI-agent detections. Each briefing explains the threat and quotes the alert text that decided it. The briefing works with no API key. A model can rewrite the wording; it cannot talk a serious alert down.

Triage a message

Paste an email. It is added to the queue and briefed with the same chain.

Sample IDS rows are a curated slice of the AIT Alert Data Set (CC-BY-4.0). The 96 MB archive stays out of git. Agent alerts use the SentinelProxy sample shape.
